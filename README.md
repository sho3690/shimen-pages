# 紙面 (Shimen) — 閲覧用

登録したニュースサイトの新着記事を、Mac内のローカルAIがまとめて要約し、
新聞の紙面の形にしたものです。ここはその**閲覧専用の控え**です。

公開URL: https://sho3690.github.io/shimen-pages/

## これは何か

- 紙面を作っているのは手元のMacです（本体は非公開）
- ここには**作り終えた紙面だけ**が置かれています
- iPhoneのホーム画面から、Macの電源が入っていなくても読めます

## 置いてあるもの / 置いていないもの

| | |
|---|---|
| 置いてある | 見出し・要約・配信元の名前・元記事へのリンク |
| 置いていない | 購読しているRSSのURL、記事の全文、既読の記録、アクセス鍵、データベース |

## 要約について

要約は**機械（ローカルの言語モデル）が自動生成したもの**で、人手による確認を経ていません。
誤りが含まれる可能性があります。**内容は必ず配信元の元記事でお確かめください。**
各見出しから元記事へリンクしています。

記事の著作権は各配信元に帰属します。ここに元記事の本文は掲載していません。

## 更新

Macで紙面を作り直し、`shimen/scripts/build_pages.sh --push` を実行すると更新されます。
自動更新はしていません（要約に手元のMacのAIが必要なため）。
